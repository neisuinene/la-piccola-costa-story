# La Piccola Costa Story

- index.html：整個故事 App（圖片已內嵌）
- story-data.js：人物、場景、對白。以後加劇情，只要換這個檔案
- manifest.json、sw.js、各尺寸 png：讓它能安裝、離線使用

上傳到 GitHub：建立新的 repository（名稱 la-piccola-costa-story，Public），一次選取全部 9 個檔案上傳，
再到 Settings → Pages 選 main 分支 / (root)。
網址會是 https://你的帳號.github.io/la-piccola-costa-story/

更新時：把 sw.js 第一行的 lpcs-v1 改成 lpcs-v2（每次加一）。
